# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Delegated: Electron with React and TypeScript. Electron delivers the requested native Linux desktop application while React supports a responsive, highly interactive editor surface without requiring a Rust toolchain on this machine.

## Users

People who work with local folders of Markdown notes, documentation, drafts, and README files on a Linux desktop. Their job is to open a document, understand its structure, revise it confidently, and save it back to disk without moving their writing into a cloud service.

## Product Purpose

Inkwell is a local-first Markdown reader and editor. It makes reading, drafting, and organizing Markdown feel calm and immediate in a dedicated desktop workspace.

## Positioning

The same document is always available as an editable source and a refined reading surface, with direct local-file access rather than a proprietary workspace or sync account.

## Operating Context

Users open individual `.md` files or folders from Linux, move between files in a document tree, write with a live preview, and save changes locally. The product is useful for notes, technical docs, project READMEs, and longer drafts.

## Capabilities and Constraints

- Native Linux desktop application.
- Local file open, folder browsing, save, and Save As are core requirements inferred from the desktop Markdown-tool brief.
- Reader and editor modes, plus a split view, are core requirements.
- No account, cloud sync, collaboration, or remote publishing is in scope for the first version.
- App name and icon are working defaults and remain open for change.

## Evidence on Hand

No supplied product copy, documents, logos, or imagery. Demonstration documents must be clearly presented as sample content.

## Product Principles

- Keep documents local and under the user’s control.
- Make reading as considered as writing.
- Reveal structure without burying the page in controls.
- Keep the editor fast, legible, and keyboard-friendly.

## Accessibility & Inclusion

- Full keyboard access for document navigation and editor actions.
- Strong text contrast and visible focus states.
- Text scaling and a comfortable default reading measure.
